## 菜鸟教程词汇包

- 来源目录：<https://www.runoob.com/?lang=zh>
- 生成脚本：`tool/generate_runoob_pack.ps1`
- 原始教程名称：123 个
- 扩展学习概念：163 个，分为“算法与数据结构”“代码语法”“常用函数”
- 一级（基础）：78 词
- 二级（进阶）：199 词，运行时包含一级全部词汇
- 三级（完整）：286 词，运行时包含一级与二级全部词汇

词条名称和对应教程链接来自公开教程目录。标准解释、典型写法与四段学习说明由本项目按技术分类重新编写，
不复制教程正文。词汇包内容覆盖教程入口、核心算法、常见代码写法和函数调用方式。

JSON 中每个词只保存一次，不通过复制词条实现分级。应用在选择二级或三级词包时，按等级关系动态包含较低级词汇，
因此搜索、编辑和词库统计不会出现同名重复词条。
